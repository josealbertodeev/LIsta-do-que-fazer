## 🎯 Como Usar

### **Adicionar Tarefas**
1. Digite o título no campo principal
2. Escolha categoria, data, tempo estimado
3. Adicione notas e marque prioridade se necessário
4. Pressione **Enter** ou clique em **"+ Adicionar Tarefa"**

### **Timer Pomodoro**
1. Clique em **"▶ Iniciar"** para começar sessão de 25 minutos
2. Use **"⏸ Pausar"** para interromper
3. Clique em **"⟲ Zerar"** para resetar

### **Metas**
1. Clique no botão **"+ Nova Meta"**
2. Defina título, descrição e número de tarefas
3. Vincule tarefas à meta ao criá-las
4. Acompanhe progresso em tempo real

### **Atalhos de Teclado**
- `Ctrl/Cmd + Enter`: Adicionar tarefa rapidamente
- `Ctrl/Cmd + K`: Focar no campo de nova tarefa
- `Ctrl/Cmd + M`: Abrir modal de nova meta
- `Ctrl/Cmd + P`: Alternar prioridade da tarefa atual
- `Esc`: Fechar modais
